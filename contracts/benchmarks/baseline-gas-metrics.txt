## Regression Detection Workflow

### Step 1: Establish Baseline
  cargo bench --bench contract_benchmarks --bench registry_benchmarks --bench achievements_benchmarks --bench qf_benchmarks 2>&1 | tee benchmark_output.txt
  # Manually review output and update this file with TBD → actual values

### Step 2: Run on New Code
  cargo bench --bench contract_benchmarks --bench registry_benchmarks --bench achievements_benchmarks --bench qf_benchmarks 2>&1 | tee new_output.txt

### Step 3: Compare (Manual)
  - Extract median CPU cycles from both files
  - Calculate % change: (new - baseline) / baseline * 100
  - Flag if any function shows > 15% regression

### Step 4: CI Integration (Planned)
  - Automated script to parse criterion output
  - Fail CI if regression > 15%
  - Generate HTML diff report for review
